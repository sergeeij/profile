# Лабораторная работа № 2 — обработка измерений на Python

**Основа:** лабораторный практикум МЭИ «Элементы радиоприемного тракта, параметры и методы измерения» (2025), лабораторная работа № 2, разделы 2.3.1–2.3.2.

Это рабочий комплект для твоих **собственных измерений**. Никаких чужих экспериментальных значений в шаблоны не добавлено. Частотную сетку выбери по исследуемому фильтру и его DataSheet, делая чаще точки в области изменения АЧХ.

## 1. Установка и запуск в PyCharm

1. Распакуй ZIP в удобную папку, например `D:\\Lab2`.
2. В PyCharm открой эту папку как проект. Укажи установленный Python.
3. Открой терминал PyCharm и выполни: `pip install -r requirements.txt`.
4. Заполняй CSV в папке `input` (в Excel или обычном текстовом редакторе).
5. Запускай файл `lab2_plot.py` (кнопкой ▶ или командой `python lab2_plot.py`).
6. Файлы `results/*.csv` содержат вычисления; `graphs/*.png` — графики для Word-отчёта.

Если исходные файлы пока пустые, программа не создаст фиктивные графики и сообщит, что данных нет.

## 2. Какие CSV заполнять

### `input/achx.csv` — раздел 2.3.1

| Столбец | Измерение или расчёт |
| --- | --- |
| `f_MHz` | Частота генератора, МГц |
| `P_filter_dBm` | Уровень **с фильтром** (рис. 10), дБм |
| `P_cal_dBm` | Уровень **без фильтра** при калибровке тракта (рис. 11), дБм |

Формула: `S21_dB = P_filter_dBm - P_cal_dBm`.

**Обязательно:** записать уровни на одинаковых частотах при одинаковых настройках анализатора. Калибровка здесь — измерение проходного тракта без фильтра, а не программная нормировка на произвольное число.

### `input/reflection.csv` — раздел 2.3.2, пункты 1–4

| Столбец | Измерение |
| --- | --- |
| `f_MHz` | Частота, МГц |
| `P_OC_dBm` | Измерительное плечо при разомкнутом OUT, дБм |
| `P_50_dBm` | То же при нагрузке 50 Ом, дБм |
| `P_filter_dBm` | То же при подключённом фильтре с нагрузкой 50 Ом, дБм |

Расчёты: `Gamma_dB = P_filter_dBm - P_OC_dBm`, `Gamma_abs = 10^(Gamma_dB / 20)`, `VSWR = (1 + Gamma_abs) / (1 - Gamma_abs)` при `Gamma_abs < 1`.

Оценка направленности/предельного динамического диапазона: `D_est_dB = P_OC_dBm - P_50_dBm`. Приближённая оценка, а не точная векторная калибровка направленного ответвителя.

**Важно:** измеряй на тех же частотах, что и АЧХ, как требует методичка; при необходимости выбирай дополнительные точки и записывай их во всех сравниваемых режимах.

### `input/attenuators.csv` — раздел 2.3.2, пункты 5–6

| Столбец | Измерение |
| --- | --- |
| `f_MHz` | Частота, МГц |
| `P_att3_dBm` | Уровень при ненагруженном аттенюаторе 3 дБ |
| `P_att6_dBm` | То же для 6 дБ |
| `P_att10_dBm` | То же для 10 дБ |

Программа сопоставляет частоту с `reflection.csv`, чтобы взять опорный ХХ (`P_OC_dBm`) **на той же частоте**. Если нужной частоты там нет, коэффициент отражения не рассчитывается и выводится предупреждение. Количество строк в трёх CSV может различаться, но для сопоставления нужны общие точки частоты.

Теория для ненагруженного идеального согласованного аттенюатора: `20lg|Gamma_in| = -2A` дБ, то есть −6, −12, −20 дБ для 3, 6, 10 дБ соответственно. Отражение зависит от характеристик настоящего устройства и измерительного стенда.

## 3. Как заполнять CSV в Excel

- Данные внутри CSV разделяются **точкой с запятой** `;`.
- Числа с десятичной частью могут содержать как `,`, так и `.` (например `-31,5` или `-31.5`).
- Не используй `дБм`, `МГц` или другие буквы **внутри ячеек с числами**.
- Оставляй ячейку пустой, если измерения не было. Не записывай `0` вместо отсутствующего результата.
- Сохраняй файл в формате **CSV с разделителем `;`**. Если Excel показывает заголовки в одной ячейке, импортируй файл через **Данные → Из текста/CSV** и выбери разделитель `;`. В Блокноте одна строка заголовков с `;` — нормально.
- Проверяй, что названия заголовков не изменились.

Для понимания формата (это **не измеренные данные**):

```csv
f_MHz;P_filter_dBm;P_cal_dBm
; ;
```

Удаляй строку `; ;`, затем вписывай реальные частоты и мощности. Заголовок оставь как есть.

## 5. Почему некоторые результаты могут быть отмечены как ненадёжные

- Для пассивного фильтра `|Gamma| > 1` физически невозможно: это признак ошибки/неопределённости скалярной оценки. При `|Gamma| = 1` отражение полное и КСВН бесконечен, такой КСВН нельзя показать на обычном графике. Программа **не подменяет** эти случаи числом 0,95: в CSV появится предупреждение.
- Если уровень при фильтре отличается от уровня при согласованной нагрузке не более чем на 6 дБ, простая оценка отражения чувствительна к ограниченной направленности и паразитным отражениям. В столбце `Quality` появится предупреждение.
- Направленность `D_est` по двум уровням — лишь оценка. Нельзя приравнивать её к точной заводской характеристике без учёта амплитуд и фаз портов, а также калибровки.
- Если пустых значений много, соответствующий график не строится или имеет пробелы; данные **не интерполируются автоматически**.

## 6. Формулы для объяснения на защите

- АЧХ (в дБ): `S21 = P_с_фильтром - P_без_фильтра`.
- Отражение (логарифмический модуль): `Gamma_dB = P_фильтр_на_CPL - P_ХХ_на_CPL`.
- Модуль: `|Gamma| = 10^(Gamma_dB/20)`.
- КСВН: `VSWR = (1 + |Gamma|)/(1 - |Gamma|)`.
- Положительные возвратные потери: `ReturnLoss_dB = -Gamma_dB` (в некоторых методичках термин Return Loss используют и для отрицательного логарифмического коэффициента отражения; сравнивай знак по определению).
- Направленность (приближённо): `D_est ≈ P_ХХ - P_50`.

## 7. Важное ограничение

Этот сценарий выполняет **скалярную** оценку отражения по уровням мощности на анализаторе спектра. Для высокоточного определения очень малого коэффициента отражения нужна комплексная (амплитудно-фазовая) калибровка стенда или векторный анализатор цепей. Наши формулы соответствуют учебной процедуре с направленным ответвителем, но не компенсируют фазовые паразитные отражения.
