ЛР №3 — ИЗМЕРЕНИЯ УСИЛИТЕЛЯ: ПРОСТАЯ ОБРАБОТКА CSV

1. КАК ПОЛЬЗОВАТЬСЯ
1) Все файлы положить в одну папку. CSV можно открыть в Excel или обычном Блокноте.
2) Вводить показания приборов в CSV (одна строка = одно измерение).
3) Разделитель столбцов — ; (точка с запятой). Для дробей подходят и 1,25, и 1.25.
4) Сохранить CSV, закрыть файл в Excel и запустить: python lr3_graphs.py
5) Готовые PNG будут в папке graphs, а расчёты в result_*.csv рядом со скриптом.
   ВСЕ графики делаются отдельно. Шрифт Times New Roman на Windows.
6) Первый запуск с пустыми CSV — нормален: скрипт покажет, каких данных не хватает.

Установить библиотеки ОДИН РАЗ (терминал PyCharm или CMD):
    pip install numpy pandas matplotlib

2. ЧТО ЗАПИСЫВАТЬ

01_gain.csv — измерение АЧХ и обратной передачи (методичка, 3.3.1)
    f_MHz                — частота, МГц
    P_forward_dBm        — уровень анализатора С УСИЛИТЕЛЕМ, P1, дБм (рис. 21)
    P_cal_dBm            — уровень БЕЗ усилителя с переходником, P2, дБм (рис. 22)
    P_reverse_dBm        — уровень при обратном подключении усилителя, дБм
    P_reverse_cal_dBm    — отдельная калибровка для обратного подключения, дБм
    Выход: Kp = P_forward - P_cal; S12 = P_reverse - P_reverse_cal.
    Если развязку пока не измеряли, оставьте последние два столбца пустыми.
    Во время калибровки фиксируйте те же настройки анализатора.

02_noise.csv — коэффициент шума (3.3.2)
    f_MHz           — частота (ТОЧНО такая же, как в 01_gain.csv)
    P_noise_dBm     — отображаемая мощность шума при включённом усилителе, дБм
    P_analyzer_dBm  — собственный шум анализатора при тех же RBW/VBW, дБм
    RBW_Hz          — RBW в Гц (например: 1000, НЕ 1 для 1 кГц)
    IL2_dB          — отдельно определённые потери КАБЕЛЯ 2, положительные дБ
    Расчёт: NF = P_noise + IL2 - (-174 + 10log10(RBW) + Kp).
    Примечание: здесь используется упрощённая формула методички, RBW ≈ шумовая полоса.
    Если шум анализатора менее чем на 10 дБ ниже измеряемого, скрипт предупреждает:
    в этом случае вывод NF может быть неточным; требуется улучшить условия измерения.
    Вход усилителя при измерении — согласованная нагрузка 50 Ом.

03_p1db_cal.csv — калибровка для P1dB (3.3.3, рис. 24/25)
    f_MHz           — частота
    Pgen_cal_dBm    — установленный на генераторе уровень при калибровке (обычно +10)
    P1_dBm          — анализатор с выходным аттенюатором и кабелем 2 (рис. 24)
    P2_dBm          — анализатор БЕЗ выходного аттенюатора и кабеля 2 (рис. 25)
    Потери выходной части: IL2 = P2-P1 (положительная величина).

04_p1db.csv — мощностная характеристика (рис. 26)
    f_MHz           — частота (как в 03_p1db_cal.csv)
    Pgen_dBm        — текущая мощность генератора, дБм
    P3_dBm          — показание анализатора с усилителем, дБм
    Расчёт входа усилителя: Pin = Pgen - (Pgen_cal - P2).
    Расчёт выхода усилителя: Pout = P3 + (P2 - P1).
    Скрипт строит Pout(Pin) и идеальную прямую Pout = Pin + Kp0.
    За Kp0 берёт значение из 01_gain.csv; если его нет, берёт среднее усиление
    первых двух точек, снятых на наименьшей входной мощности.
    Если кривая достигает компрессии 1 дБ — IP1dB/OP1dB определяются интерполяцией.
    Если не достигает, будет сообщение. Добавьте измерения рядом с изгибом.
    Результат OP1dB(f) строится отдельно.
    ВНИМАНИЕ: следите за пределом анализатора и мощностью аттенюаторов!

05_ip3_cal.csv — калибровка для IP3 (3.3.4, рис. 27/28)
    f_MHz      — центральная частота двухтонового сигнала
    P1_dBm     — показание на анализаторе с выходным аттенюатором и кабелем 3
    P2_dBm     — показание без них; IL3 = P2-P1.

06_ip3.csv — двухтоновое измерение IP3 (рис. 29)
    f_MHz            — центральная частота, МГц
    P_in_tone_dBm    — мощность ОДНОГО тона непосредственно на входе усилителя,
                       по отдельной калибровке входной части тракта, дБм
    P_tone_an_dBm    — уровень ОДНОГО основного тона на анализаторе, дБм
    P_IM3_an_dBm     — уровень ОДНОГО продукта третьего порядка на анализаторе, дБм
    Для каждого центрального f требуется несколько строк с разными уровнями тонов.
    Выходной тракт корректируется на IL3:
       P_tone_out = P_tone_an + IL3
       P_IM3_out = P_IM3_an + IL3
       IMD3 = P_tone_out - P_IM3_out
       OIP3 = P_tone_out + IMD3/2
       IIP3 = OIP3 - Kp (Kp из 01_gain.csv).
    График 2 кривых Pout(Pin): основной тон и продукт IM3 на одном графике —
    так требуется для демонстрации наклонов 1:1 и 3:1. Прочие графики раздельно.
    Если P_in_tone пока неизвестна, можно оставить пустой: численный OIP3 всё ещё
    рассчитывается, но график от входной мощности нельзя построить.
    Расстояние между частотами генераторов — 1 МГц.
    Показания основных тонов должны быть примерно одинаковыми.
    Проверка собственного IM3 измерительного тракта — обязательный контроль по 3.3.4.

3. ВАЖНЫЕ ЗАМЕЧАНИЯ
* Все уровни P_..._dBm — В ДБМ; потери IL... — В ДБ; частоты — В МГц.
* Пустые строки разрешены, вымышленные значения не нужны.
* Частоты калибровок и измерений должны совпадать.
* Используйте отдельные графики для отчёта, без объединения разных задач в одну фигуру.
* Формула Pout = P3 + IL2/IL3 использует ПОЛОЖИТЕЛЬНЫЕ потери,
  определённые как P2-P1. Это важно: в методичке встречается несогласованный знак.
* Рассчитанная IP3 — экстраполированная точка; не пытайтесь физически достигать её.
* Результаты — предварительные до проверки корректности измерений и калибровок.

07_reflection_optional.csv — необязательное измерение S11/S22, если выдаст преподаватель.
    f_MHz; P_open_in_dBm (ХХ-опора); P_ref_in_dBm (отражение входа усилителя);
    P_open_out_dBm (ХХ-опора); P_ref_out_dBm (отражение выхода усилителя).
    S11 = P_ref_in - P_open_in, S22 = P_ref_out - P_open_out (дБ).
    Метод предполагает использование направленного ответвителя и ограничен его
    направленностью; для оценки ошибок нужен отдельный контроль с 50-омной нагрузкой.
